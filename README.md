# znanylekarz

Materiały forensyczne do sprawy **Net123 sp. z o.o. przeciwko Znanylekarz sp. z o.o.**
(ochrona praw producenta bazy danych / prawo autorskie / nieuczciwa konkurencja) —
wykazanie chronologicznego i sekwencyjnego pobierania (scrapowania) danych
mylekarze.pl przez znanylekarz.pl w latach ~2011–2014.

- [`forensja/`](forensja/) — metodyka wykrywania przejęć + reprodukowalne narzędzie
  (parsery, markery „odcisku palca”, scoring dowodowy, pilotaż arkusza „Ortopedzi”).
  Zacznij od [`forensja/README.md`](forensja/README.md).

> Narzędzie działa **tylko w trybie odczytu** na autoryzowanym archiwum procesowym.
> Dane osobowe i poświadczenia pozostają poza repozytorium (`forensja/.gitignore`).
